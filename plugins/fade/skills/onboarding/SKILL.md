Set up a brand in Fade

Call fade_onboarding (free) and follow the guide it returns, from the first step that is not done yet. It is served fresh by Fade, so skip any version check or update hint inside it. If Fade is signed out or not connected, sign the person in first: if Fade offers an authenticate tool, call it; if you can run shell commands, open the link it returns in the person's browser yourself (open on macOS, xdg-open on Linux, start on Windows) and tell them to finish signing in with Wix there, otherwise give them the link. Without that tool, tell them to connect https://mcp.tryfade.ai/mcp and sign in with Wix.
